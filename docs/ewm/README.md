# EWM-Projektwissen – Methodik und Vorlagen

Dieser Ordner ist die **kundenneutrale** Wissensbasis für SAP-EWM-Projekte:
Vorlagen und Checklisten, mit denen Anforderungen (Requirements) strukturiert
erfasst, bewertet und nachverfolgt werden.

## Wichtiger Hinweis zur Vertraulichkeit

Dieses Repository ist **öffentlich**. Deshalb gilt:

- **Keine** kundenspezifischen Inhalte hier ablegen — keine Namen, keine
  E-Mail-Adressen, keine System-IDs/Mandanten, keine Ticketnummern, keine
  Meeting-Links, keine Auszüge aus als „INTERNAL" klassifizierten Dokumenten.
- Kundenanforderungen aus Confluence, SolMan oder Jira gehören in eine
  **nicht-öffentliche** Ablage (privates Repo, SharePoint/OneDrive des
  jeweiligen Projekts).
- Hier liegen nur wiederverwendbare Vorlagen und Fragenkataloge.

## Inhalt

| Datei | Zweck |
|---|---|
| `requirement-template.md` | Vorlage für ein einzelnes EWM-Requirement |
| `requirement-gathering-checkliste.md` | Fragenkatalog zur Anforderungsaufnahme EWM |
| `confluence-uebernahme.md` | Vorgehen, um Requirements aus Confluence in die Projektwissensbasis zu übernehmen |

## Arbeitsweise

1. Anforderungen in der Quelle (Confluence/Jira) **lesen**, nicht ändern.
2. Je Requirement eine Datei nach `requirement-template.md` in der
   projektspezifischen (privaten) Ablage anlegen.
3. Quelle immer als Link + Abrufdatum + Version festhalten
   (Confluence-Seiten ändern sich).
4. Offene Punkte explizit als Frage an Business/IT formulieren, nicht raten.
